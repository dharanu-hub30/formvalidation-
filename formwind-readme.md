# WindWave Shop – Form Validation

Practicum site on developing a form with validation using JavaScript, themed on wind energy for smart cities.

## Files
- `formwind-page.html` – the page
- `formwind-style.css` – styles and animations
- `formwind-script.js` – oninput and onsubmit validation, running total, bill
- `vercel.json` – opens the page at the site root (keep this exact name)

## Upload to GitHub
1. Create a NEW repository for this site.
2. Add file -> Upload files, drag in the unzipped files (not the zip), and commit.

## Deploy on Vercel
1. Vercel -> Add New -> Project, import the repository.
2. Framework Preset: Other. Leave build settings empty. Deploy.

Note: every site has its own `vercel.json`, so keep each site in a separate repository.
